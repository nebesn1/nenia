## Color palette references

Nenia uses selected colors associated with these projects and maps them into
its own semantic roles. Some final HEX values and role assignments include
Nenia-specific adjustments; they should not be read as exact upstream theme
implementations.

- [Nord](https://www.nordtheme.com/) — palette by Arctic Ice Studio and Sven
  Greb; upstream Nord repository metadata identifies MIT licensing.
- [Catppuccin](https://catppuccin.com/palette/) — palette by Catppuccin
  contributors; upstream project identifies MIT licensing.
- [Gruvbox](https://github.com/morhetz/gruvbox) — palette by morhetz and
  contributors; upstream repository identifies MIT/X11 licensing.

Only selected color values are referenced; Nenia does not bundle the upstream
theme engines or stylesheets.
